ORIGINAL GIVENS AND TRACEABLE UNIT CORRECTION
Structural steel Rm=70e7 N/m^2=700 MPa; carbide P25; T=20 min=1200 s; g=8; kappa=90 degrees; PM1=10 kW=10000 W; eta=0.8.
The statement prints 70e7 N/mm^2. The matching worked page 12 explicitly uses Rm=70e7 N/m^2 and the structural-steel S-13 row, confirming the unit correction for this exact task. This is not permission to repair arbitrary unreadable or conflicting units in other problems.

UNITS FOR THIS EMPIRICAL MODEL
In the equations below: a (cutting depth) in m; s (feed per revolution, also written f) in m/rev; T in s; v in m/s; Fv in N; PM in W. Feed BRANCH bounds alone are in mm/rev. A=a*s is in m^2; multiply by 1e6 to get mm^2. Coefficient numerical values must not be used with mm substitutions in these equations.

EXACT SELECTED APPENDIX DATA
S-13, structural steel Rm=70e7 N/m^2: Ck=3.95e8; x1=1; y1=0.78. The printed Ck multiplier 10^8 is included.
S-5, kappa=90 degrees: zeta_k=0.74.
S-8, structural/carbon/alloy/cast steel reference Rm=75e7 N/m^2; outer longitudinal turning; HM P25:
  s_mm <= 0.3:       Cv=0.9197; x=0.15; y=0.20; m=0.20; reference life=60 min.
  0.3 < s_mm <=0.75: Cv=0.2713; x=0.15; y=0.35; m=0.20; reference life=60 min.
  s_mm > 0.75:       Cv=0.1324; x=0.15; y=0.45; m=0.20; reference life=60 min.
The printed middle row says s<=0.75; the nested low-feed row governs s<=0.3. Tutorial pages 13 and 16 confirm switching rows between passes.
S-8 material correction: zeta_mrp=75e7/Rm=75/70 for these givens.
S-8 tool-life correction: zeta_T=(Tref/T)^(1/z). Tutorial page 14 explicitly selects z=2 for this steel/P25 task, so zeta_T=sqrt(60/20)=sqrt(3). z=2 is this worked task's adopted choice, not a universal value for all tools/materials.
Let Z=zeta_k*zeta_mrp*zeta_T=0.74*(75/70)*sqrt(3). Retain full precision.

COURSE EQUATIONS, INCLUDING ITS TOOL-LIFE CONVENTION
A=a*s; g=a/s; a=g*s.
Fv=Ck*a^x1*s^y1.
v=Cv*Z/(T^m*a^x*s^y).
PM=Fv*v/eta=Ck*Cv*Z*a^(x1-x)*s^(y1-y)/(eta*T^m).
s=[PM*eta*T^m/(Ck*Cv*Z*g^(x1-x))]^[1/(x1-x+y1-y)].
The tutorial uses both T^m and zeta_T in the speed expression. These equations preserve the instructor's stated convention rather than substituting a different handbook model.

SINGLE PASS: SOLVE THEN CHECK THE FEED BRANCH
For the middle branch:
s1=[10000*0.8*1200^0.2/(3.95e8*0.2713*Z*8^0.85)]^(1/1.28)
  =0.000354492666953646 m/rev=0.354492666953646 mm/rev.
0.3<0.354492666953646<=0.75, so this branch is valid.
a1=8*s1=0.002835941335629168 m.
Amax=a1*s1=1.005320407391269e-6 m^2=1.005320407391269 mm^2.

TWO EQUAL-DEPTH PASSES, SAME g
a2=a1/2=0.001417970667814584 m.
s2=a2/8=s1/2=0.000177246333476823 m/rev=0.177246333476823 mm/rev.
s2_mm<=0.3: select Cv2=0.9197, y2=0.20, x2=0.15, m2=0.20.
PM2=[3.95e8*0.9197*Z*(0.001417970667814584)^0.85*(0.000177246333476823)^0.58]/[0.8*1200^0.2]
   =3820.890460763603 W=3.820890460763603 kW.
Power reduction=(PM1-PM2)/PM1*100=(10000-3820.890460763603)/10000*100=61.79109539236397 percent.
This is operating motor power for each pass, not the sum of sequential-pass powers or total machining energy. A2=Amax/4 does not imply PM2=PM1/4 because speed and empirical coefficients change.
